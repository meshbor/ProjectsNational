# Национальные проекты — рабочее место

Отдельный сайт, не семейный дайджест. Сюда перенесено рабочее место из [`meshbor/kvartira-zadachi`](https://github.com/meshbor/kvartira-zadachi) (ветка [`cursor/national-projects-c3a9`](https://github.com/meshbor/kvartira-zadachi/pull/12)).

Сейчас подробно разобран один федеральный проект: **«Многодетная семья»** (нацпроект «Семья»). Остальные 19 нацпроектов открываются как черновик той же канвы по данным каталога. Подрядчиков и компании не выдумываем.

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- Слева — все 20 нацпроектов по убыванию бюджета; колонку можно сузить или свернуть
- В центре — канва выбранного проекта (для «Семьи» — ФП «Многодетная семья»)
- Справа — официальные источники

## Тесты

```bash
npm test
npm run build
```
