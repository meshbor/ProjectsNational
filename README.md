# Национальные проекты — рабочее место

Отдельный сайт, не семейный дайджест. Сюда перенесено рабочее место из [`meshbor/kvartira-zadachi`](https://github.com/meshbor/kvartira-zadachi) (ветка [`cursor/national-projects-c3a9`](https://github.com/meshbor/kvartira-zadachi/pull/12)).

Сейчас разбираем один федеральный проект: **«Многодетная семья»** (нацпроект «Семья»). Остальные 19 нацпроектов и остальные федеральные проекты «Семья» видны списком со статусом **в работе**. Подрядчиков и компании не выдумываем.

## Как запустить

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000).

- Слева — канва ФП «Многодетная семья»: меры, слоты исполнителей, задачи
- Справа — официальные источники
- Остальные нацпроекты открываются как туду «в работе»

## Тесты

```bash
npm test
npm run build
```
